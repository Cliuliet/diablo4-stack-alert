# Diablo IV Stack Alert

暗黑破坏神4的100层语音提醒器。Windows免安装小工具，通过固定区域截图匹配100层样本，播报“层数已满”。不读取游戏内存，不自动操作游戏。

## 使用

1. 下载 `dist/StackAlert-v2.exe`，双击运行；升级前先关闭旧版。
2. 游戏使用无边框窗口模式，目标技能达到100层时，点击“框选100数字”，紧贴完整的100数字框选。
3. 点击“试听语音”，确认声音可用，再点击“开始监测”并切回游戏。

会记住选框和样本，持续满层只提醒一次。分辨率、界面缩放、技能位置或窗口位置改变后需要重新框选。系统需要 Windows 桌面环境、.NET Framework 4.x 和可用的系统语音；优先使用中文语音。

## 工作方式

- 约每50毫秒对固定位置截图，与满层样本比较；不是OCR，不满屏查找数字。
- 默认相似度阈值85%，连续两次确认；达到96%且不低于设定阈值时可立即触发。
- 播报后，低于阈值10个百分点的明确不匹配持续150毫秒，可恢复提醒资格。
- 前台窗口检测默认开启。仅窗口标题含 Diablo 或“暗黑”时监测，工具自身窗口除外。
- 电脑负载、画面遮挡、截图变化可能导致漏报或误报。

## 漏报排查

漏报后尽快点击“保存检测记录”，保存最近约2分钟的检测事件、最近的局部截图和100样本。记录包含匹配度、实际检测间隔、状态和语音请求事件。语音请求不代表实际已听到声音。文件不会自动上传。

设置保存在 `%LOCALAPPDATA%\D4StackAlert`。详细说明见 [使用说明.txt](使用说明.txt)。

## 编译

在 Windows PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

脚本使用系统 .NET Framework 编译器，输出 `dist/StackAlert-v2.exe`。完整源码在 `src/StackAlert.cs`。

## 验证范围

已通过100/19原始截图区分，以及持续满层、短暂闪动、快速恢复提醒、短暂高匹配、两帧确认、过时帧排除和阈值抖动测试。尚未在真实游戏战斗中验证稳定性。
